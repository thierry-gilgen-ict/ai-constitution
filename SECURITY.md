# Security

Load for identity, authorization, private data, financial integrity or irreversible lifecycle work.

- Instructions, credentials, source evidence, approvals and spending authority are distinct; none grants another.
- Preserve project/customer/private trust domains. Send only necessary authorized data to an approved provider; public policy contains no private inventories.
- Keep fail-closed defaults. Test wrong entity/tenant, revoked or absent permission, stale input, reordered responses and failed persistence at real boundaries.
- High/critical risk requires independent exact-revision verification. A second same-account agent provides evidence, not an enforced human approval.
- Keep credential incidents on their existing response path. Governance does not authorize secret printing, migration or rotation.
