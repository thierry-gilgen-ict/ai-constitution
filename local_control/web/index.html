Better together.

            them here.
          

          

          
Display drivers, including virtual adapters. Checks run on each computer; private hardware details stay in your cluster.

        

        
Local only, with a fallback you choose.
Every route uses local model weights. No cloud fallback is enabled.
The preference applies at the next Gaming transition. Ineligible, maintained or incompatible machines cannot be selected. An in-flight generation is never replayed.
Recent machine health
Update without breaking a session.
Drain each runtime on this computer before updating Ollama. A tested remote fallback keeps new requests moving. Updates use the official package manager and may need your input.
Leave maintenance after the updated runtime is running. Each remote computer updates its own runtime; there is no remote shell access.

        

          
Add a machine

          

            On the other computer, install Ollama and this checkout, then start
            a private HTTPS worker. Copy its pairing record over a trusted
            channel.
          

          
python -m pip install -r requirements-local-node.txt
python scripts/local_control.py node --address PRIVATE_IP
# In another terminal:
python scripts/local_control.py pairing --address PRIVATE_IP

          

            
          

          

            Encrypted connections, pinned certificates, no network scanning.
            Pairing records are secrets. This cluster routes whole requests; it
            does not pool GPU memory.

What continues when you switch?

          

            

              FINISH
              
The current response

              

                It stays on the machine where it started. Nothing is replayed
                midstream.
              

            

            

              ROUTE
              
The next request

              

                It carries the conversation history to the chosen fallback. A
                healthy fallback is required.
              

            

            

              RELEASE
              
The local GPU

              

                Managed GPU models unload after their active responses finish.
                Live memory is checked afterward.
