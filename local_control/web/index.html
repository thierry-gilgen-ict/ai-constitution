A HOME FOR YOUR COMPUTE

Better together.

Windows PCs, Macs and Linux machines. Give each a job and manage them here.

Add a machine

On the other computer, install Ollama and this checkout, then start a private HTTPS worker. Copy its pairing record over a trusted channel. 

python -m pip install -r requirements-local-node.txt
python scripts/local_control.py node --address PRIVATE_IP
# In another terminal:
python scripts/local_control.py pairing --address PRIVATE_IP

Encrypted connections, pinned certificates, no network scanning. Pairing records are secrets. This cluster routes whole requests; it does not pool GPU memory.

01 / CODEX CLI

One command to start.

Run from your AI Constitution checkout. Your usual Codex configuration stays intact. 

python scripts/local_control.py codex --project /path/to/project

Uses the Responses API, a 64K context setting and the stable model alias. Start new sessions through this launcher to use switching.

02 / CURSOR

Stay in your editor.

Open a workspace with a ready-made Local Codex terminal task.

python scripts/local_control.py cursor --project /path/to/project

Then choose Terminal → Run Task → AI Constitution: Local Codex.

This runs Codex inside Cursor. Cursor's native Agent and Tab keep their own providers; localhost is not a native fully local Agent backend.

What continues when you switch?

FINISH

The current response

It stays on the machine where it started. Nothing is replayed midstream.

ROUTE

The next request

It carries the conversation history to the chosen fallback. A healthy fallback is required.

RELEASE

The local GPU

Managed GPU models unload after their active responses finish. Live memory is checked afterward.

Existing direct-provider sessions cannot be migrated in place. Tool behavior and speed can vary by model. The desktop app's running assistant is not switched by this dashboard.
